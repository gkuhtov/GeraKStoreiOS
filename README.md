# GeraKStore iOS

Нативный SwiftUI starter для iOS 16+ / Swift 5.9 с визуальной темой Rose Neon.

## Сборка
1. Установить Xcode на macOS и XcodeGen (`brew install xcodegen`).
2. В каталоге проекта выполнить `xcodegen generate`.
3. Открыть `GeraKStoreiOS.xcodeproj` в Xcode и выбрать Team для подписи приложения.

## Важно
- Каталог в `RootTabView` содержит демонстрационные данные, а не реальный удалённый репозиторий приложений.
- В текущем starter кнопка «ЗАГРУЗИТЬ» не устанавливает IPA. Для production нужны проверенный источник метаданных, загрузчик, сервер/поток подписи и корректная обработка ошибок.
- iOS не предоставляет обычным приложениям API для бесшумной установки сторонних приложений. `itms-services` запускает системный процесс установки с ограничениями платформы.
- Background task — ограниченное системой время для завершения работы, а не постоянный фоновый режим.
- Пароль .p12 намеренно не сохраняется. Provisioning profile здесь читается для базовой диагностики; это не полноценная криптографическая проверка подписи.
- Замените Telegram URL в `Config/StoreConfig.swift` на реальные адреса проекта.
