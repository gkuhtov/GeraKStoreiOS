# GeraKStore iOS 📱✨

Кастомный нативный клиент стороннего магазина приложений для iOS, созданный на **SwiftUI** с дизайном **Liquid Glass** и неоновыми розовыми акцентами (*Rose Neon*).

---

## 🚀 Основные возможности

* **Нативный интерфейс Liquid Glass:** полупрозрачные карточки, фаска с градиентом, динамический живой фон.
* **4 основные вкладки:**
  * **Сегодня:** баннеры обновлений, статус профиля разработчика и приложения, удаленные из App Store.
  * **Игры:** каталогизация по жанрам (*Экшен*, *Гонки*, *Стратегии*, *РПГ*).
  * **Приложения:** прикладной софт (*Банки*, *Соцсети*, *Фото/Видео*, *Утилиты*).
  * **Поиск:** сквозной поиск, история запросов и глубокая сортировка (по дате, размеру, названию).
* **Безопасность:** защита входа через Face ID (`LocalAuthentication`).
* **Детальная страница:** подтягивание официальных скриншотов через iTunes API, выбор предыдущих версий (архив IPA) и блок целостности (SHA-256, аудит dylib).
* **Zero-Popup Установка:** локальный HTTP OTA-сервер на базе Apple `Network.framework` (`localhost:8080`) для бесшовной установки через `itms-services://`.
* **Dynamic Island & Live Activities:** отображение этапов скачивания, подписи и установки на экране блокировки и в Dynamic Island.

## 🛠 Архитектура репозитория

```
GeraKStore/
├── Config/           # Конфигурации путей, тем (ThemeConfig) и репозитория
├── DynamicIsland/    # ActivityKit виджет для Dynamic Island и Lock Screen
├── Models/           # Модели данных каталога (AppItem, AppVersionRecord)
├── Services/         # OTA сервер, фоновые задачи, тактильный отклик, загрузчик
└── Views/
    ├── Components/   # Карточки, онбординг, настройки, детальные страницы
    └── Tabs/         # Экраны 4 основных вкладок (Today, Games, Apps, Search)
```

## 📦 Добавление приложений в каталог
Каталог управляется через файл `apps.json`. Любое изменение в файле мгновенно отображается у всех пользователей стора без пересборки клиента.
